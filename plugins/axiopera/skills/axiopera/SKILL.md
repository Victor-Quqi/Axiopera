---
name: axiopera
description: Run other coding agent CLIs (Claude Code, Codex, Grok Build) as background sub-agents with the axiopera command, and collect their results, questions and approval requests. Use when the user wants work handed to another agent or model, several agents working in parallel, a review or second opinion from a different agent, or a task that keeps running after this session ends.
---

Before your first axiopera command in a session, run `axiopera guide` and follow it.

If `axiopera` is not found, tell the user to install it: https://github.com/Victor-Quqi/Axiopera#install
